# Portfolio website

Backup of Summer-Lee Schoenfeld's portfolio site project, exported from Claude Design.

## Pages

- `About.dc.html` — About page (entry page)
- `Portfolio.dc.html` — Portfolio / case studies
- `Enzo Design System.dc.html` — type, color, spacing and button system
- `Canvas.dc.html` — blank canvas
- `export/about.html` — bundled, standalone About page

## Folders

- `assets/` — images, GIFs and resume used by the pages
- `uploads/` — original uploads and pasted references
- `screenshots/` — review screenshots

`support.js` and `image-slot.js` are the runtime the `.dc.html` pages load; `.image-slots.state.json` stores the images placed in image slots. `compat.json` is the page list.
